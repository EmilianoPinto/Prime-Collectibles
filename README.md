# Prime Collectibles

E-commerce web application for Transformers collectibles.

This project is currently in development and is being built as a full-stack web application using modern web technologies.

## About the Project

Prime Collectibles is an online store focused on collectibles figures.

The project was created to practice and demonstrate full-stack web development, including frontend development, API integration, database management, and e-commerce functionality.

## Technologies

* **Next.js** — React framework for the application
* **React** — User interface and component development
* **JavaScript** — Application logic
* **Tailwind CSS** — Styling and responsive design
* **PostgreSQL** — Product database
* **Node.js** — Backend environment
* **Git & GitHub** — Version control

## Features

* Product catalog
* Product search
* Product category filtering
* Product sorting
* Individual product pages
* Shopping cart
* Add and remove products from the cart
* Increase and decrease product quantities
* Product data stored in PostgreSQL
* API routes for product management
* Responsive user interface

## Database

The application uses PostgreSQL to store product information.

The backend communicates with the database through API routes built with Next.js.
